# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of ZYRO and user desktop systems very seriously. ZYRO interacts directly with user files, applications, and system settings.

If you believe you have discovered a security vulnerability in ZYRO, please **do not** open a public issue. Instead, please report it responsibly by sending an email to:

`security@zyro-ai.org` (or directly via private GitHub Security Advisory)

### What to Include in Your Report
- A detailed description of the vulnerability.
- Steps or code to reproduce the issue.
- Potential impact on the user's host operating system.
- Any proposed fixes or remediations.

We will acknowledge receipt within 48 hours and work with you on a timely resolution and disclosure schedule.
